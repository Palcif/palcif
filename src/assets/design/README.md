# Palestinian Community website assets

This pack contains cropped PNG assets from the enhanced homepage mockup, plus a few production-friendly SVG pattern assets.

Recommended usage:
- Use `tatreez-main-border.png` or `svg/tatreez-border.svg` as a horizontal divider between the hero and content sections.
- Use `keffiyeh-footer-strip.png` or `svg/keffiyeh-pattern.svg` for subtle background accents.
- Use `hero-collage-full.png` as the hero visual if you want to preserve the current mockup look quickly.
- For production, rebuild text like the headline, buttons, and navigation in HTML/CSS instead of using text inside image crops.

Color tokens are in `palette-and-usage.css`.
